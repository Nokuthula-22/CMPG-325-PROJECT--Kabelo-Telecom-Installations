Project Overview
 
This project was developed for CMPG 325 (Computer Networks) at North-West University. The objective is to design, simulate, configure, test, and document a computer network solution for Kabelo Telecom Installations (Rustenburg). The network is implemented in Cisco Packet Tracer and addresses the client's requirements, security constraints, and future expansion needs.
